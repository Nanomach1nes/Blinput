# ⌨️ Blinput — Интерактивный тренажер печати

<p align="center">
  <b>Blinput</b> — это современная веб-платформа для тренировки и развития навыков слепой печати, сочетающая в себе скорость, геймификацию, продвинутую статистику и соревновательный элемент.
</p>

---

## 🚀 Основной стек технологий

### **Бэкенд (Backend)**
* **Python / FastAPI** — быстрый асинхронный REST API.
* **SQLAlchemy** — ORM для работы с реляционной базой данных.
* **SQLite** — легковесная база данных (`blinput.db`).
* **JWT & Passlib / Bcrypt** — безопасная аутентификация и хэширование паролей.

### **Фронтенд (Frontend)**
* **React** — компонентный пользовательский интерфейс.
* **Vite** — молниеносный сборщик и инструмент разработки.
* **Modern CSS / Custom UI** — стильный кастомный интерфейс в темной cyberpunk-стилистике.

---

## ✨ Ключевой функционал

* ⚡ **Интерактивный тренажер:** Режимы печати по словам и времени, генерация случайных текстов, подсчет скорости (WPM / CPM) и точности в реальном времени.
* 🏆 **Таблица лидеров:** Сортировка участников по скорости, точности и накопленному опыту (EXP) за разные периоды (день, неделя, всё время).
* 📈 **Профиль и статистика:** Отслеживание прогресса, сохранение сессий заездов.
* 🎮 **Система прокачки и наград:** Получение уровней за заработанный опыт и разблокировка достижений.
* 🔐 **Авторизация:** Регистрация и вход пользователей с защищенными сессиями.

## ⚙️ Инструкция по локальному запуску

### 1. Клонирование репозитория
Bash
git clone [https://github.com/Nanomach1nes/Blinput.git](https://github.com/Nanomach1nes/Blinput.git)
cd Blinput

2. Запуск Бэкенда (FastAPI)

Создай и активируй виртуальное окружение, установи зависимости и запусти сервер:
Bash

# Создание виртуального окружения
python -m venv .venv

# Активация (Windows PowerShell)
.venv\Scripts\Activate

# Установка зависимостей
pip install -r requirements.txt

# Переход в папку бэкенда и запуск Uvicorn
cd backend
uvicorn app.main:app --reload --port 8000

Бэкенд будет доступен по адресу: http://localhost:8000 (документация API: http://localhost:8000/docs).
3. Запуск Фронтенда (React + Vite)

Открой новое окно терминала в корне проекта и выполни:
Bash

cd frontend

# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

Фронтенд запустится по адресу: http://localhost:5173.
